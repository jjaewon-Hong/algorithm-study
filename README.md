# algorithm-study

Winter vacation weekly problem-solving study using Baekjoon Online Judge.

## 🚀 Rules

* **Collaborative Learning**: Weekly problem-solving with C++ and JavaScript colleagues. (3 members total).
  
  **[Meetings : Wed & Sun]**
* **Peer Review**: Compare logic differences (Python vs. C++ vs. JS) and discuss optimizations.
* **No AI Assistance**: To strengthen pure problem-solving and thinking skills. But if no progress is made after at least an hour, reference is allowed.
